# App Store Connect — IAP Review Screenshots

Apple requires ONE **Review Screenshot** attached to each auto-renewable subscription product in App Store Connect. The screenshot proves the item is available for purchase in the app.

You only need to upload **one** screenshot per product. The 6.7" versions are recommended.

## How to attach

1. App Store Connect → **My Apps → NarcCheck AI → Monetization → Subscriptions**
2. Open the "Pro Annual" product → **Review Information** section → **Upload** the Annual screenshot
3. Repeat for "Pro Monthly" with the Monthly screenshot
4. Both products should now show state **"Ready to Submit"**

## Notes

- Prices in the screenshots ($8.99 monthly / $60 annual) are the final prices you intend to charge on the App Store. Set the matching **Price Tier** in App Store Connect when creating each subscription.
- If you change the price after submission, re-generate these screenshots so they always match the current ASC price.
